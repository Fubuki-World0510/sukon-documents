# PRIVACY POLICY

## 1. INTRODUCTION

This privacy policy explains how Sukon Discord Bot ("we", "our", "Sukon Bot") collects, uses, and protects your information when using our service. This policy complies with Vietnam's Network Information Security Law No. 86/2015/QH13 and current legal regulations of Vietnam.

## 2. INFORMATION WE COLLECT

### 2.1. Automatically Collected Information

- **Discord IDs**: User and Discord server IDs for identification and service provision
- **Server Information**: Server name, server ID, server settings for bot customization, Discord server information between you and us

### 2.2. User-Provided Information

- **Personal Music Playlists**: Songs saved to playlists
- **Language Settings**: Bot display language preferences
- **Message Content**: Only messages related to bot commands and counting functions
- **Server Backup**: Server backup data when using backup functionality

### 2.3. Administrative Data

- **Action Logs**: Administrative actions such as ban, kick, mute
- **Server Settings**: Command prefixes, log channels, automation settings
- **Temporary Channel Information**: Settings and permissions for temporary voice channels

## 3. PURPOSE OF INFORMATION USE

### 3.1. Service Provision

- Processing Discord commands and user interactions
- Playing music from platforms such as SoundCloud, Spotify, etc.
- Managing music queues and audio functions
- Providing anime/manga information from public APIs

### 3.2. Experience Customization

- Storing language settings and personal preferences
- Maintaining personal music playlists
- Remembering server settings and custom prefixes
- Providing AFK functionality and notifications

### 3.3. Operations and Maintenance

- Logging errors for technical troubleshooting
- Usage statistics to improve performance
- Preventing spam and service abuse
- Server data backup and recovery

### 3.4. Legal Compliance

- Supporting investigations when requested by competent authorities
- Implementing security measures according to Vietnamese law

## 5. DATA SECURITY AND STORAGE

### 5.1. Security Measures

- **Transmission Encryption**: All data is encrypted using TLS/SSL
- **Storage Encryption**: Sensitive data is encrypted in the database
- **Access Limitation**: Only authorized personnel can access data
- **Regular Backup**: Periodic data backup with encryption

### 5.2. Storage Duration

- **Active Data**: Stored during bot usage period
- **System Logs**: Stored for maximum 90 days
- **AFK Data**: Automatically deleted when AFK status ends
- **Temporary Cache**: Automatically deleted after 24 hours
- **Inactive Data**: Deleted after 6 months of non-use
