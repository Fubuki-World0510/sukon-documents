## 2. SERVICE DESCRIPTION

### 2.1. Music Features

- **Multi-platform Music Playback**: SoundCloud, Deezer, Source, Spotify (metadata)
- **Queue Management**: Add, remove, sort, shuffle songs
- **Audio Filters**: 15+ audio effects (Nightcore, Bass boost, Vaporwave, etc.)
- **Loop Modes**: Loop song, loop queue, autoplay
- **Personal Playlists**: Save and manage personal playlists
- **Advanced Controls**: Seek, pause, resume, volume adjustment

### 2.2. Server Management

- **Moderation**: Ban, kick, mute, voice channel management
- **Automation**: Auto-reply, counting system, AFK system
- **Server Backup**: Backup and restore server configuration
- **Temporary Channels**: Auto-create and delete voice channels on demand
- **System Logging**: Record important activities
- **Flexible Settings**: Customize prefix, language, command permissions

### 2.3. Entertainment and Utilities

- **Anime/Manga Search**: Information from public APIs
- **Mini Games**: Counting, trivia, and other games
- **User Utilities**: Avatar, server info, Wikipedia, Google
- **AFK System**: Away status notifications
- **Multi-language**: Support for Vietnamese and English

### 2.4. Technical Services

- **High Uptime**: Auto-recovery system when errors occur
- **API Endpoints**: For third-party applications
- **Webhook Support**: Integration with other services
